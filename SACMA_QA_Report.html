1Tóm tắt hiểu biết sâu sắc về dự án

SACMA là hệ thống quản lý chi phí du học Hàn Quốc với business logic phức tạp xoay quanh Cost Calculation Engine — tính toán real-time tổng chi phí trọn gói dựa trên nhiều tầng biến số:

  • Cố định (VNĐ): Học tiếng (13M), Tư vấn (39M), Phí trung tâm (11M), Vé máy bay (8M), KTX VN
  • Theo hệ visa (KRW): Học phí trường, Phí apply, Phí nhập học — riêng biệt cho D4-1, D2-1, D2-2, D2-3M, D2-3P, D2-6, Exchange, Short-term
  • Tùy chọn: KTX (loại phòng + số kỳ), Sổ tiết kiệm, Học bổng TOPIK (giảm % học phí)
  • Multi-currency: VNĐ + KRW hiển thị song song, có USD estimate

Sau khi phân tích toàn bộ 196 file TypeScript/React, tôi xác định 3 bug nghiêm trọng trong calculation engine, 22 API routes được viết đầy đủ nhưng chưa được gọi từ frontend, và portDetector sẽ phá vỡ hoàn toàn app trên production.

Kết luận nhanh: Backend và UI đều tốt. Vấn đề chính nằm ở (1) tính toán tiền tệ không nhất quán, (2) phần lớn features chưa kết nối frontend-backend, (3) thiếu production config cơ bản.

3Critical Bugs phát hiện trong source code

🔴 BUG-001 [CRITICAL] — 3 định nghĩa EXCHANGE_RATES khác nhau cho cùng 1 currency
src/constants/scholarships.ts: KRW_TO_VND: 20 (1 KRW = 20 VNĐ — SAI HOÀN TOÀN)
src/constants/feeDefaults.ts: vndToUsd: 25500, krwToUsd: 1350 (logic ngược)
src/app/context/CurrencyContext.tsx: KRW: 18.9 (1 KRW = 18.9 VNĐ — gần đúng)
Hậu quả: Cùng một khoản tiền KRW được tính ra VNĐ khác nhau tuỳ component → tổng chi phí sai lệch lên đến 40%.
🔴 BUG-002 [CRITICAL] — Công thức quy đổi KRW→VNĐ sai trong StudentMonitoring
StudentMonitoring.tsx:172:
fixedCostKRW_inVND = fixedCostKRW × EXCHANGE_RATES.krwToUsd × (EXCHANGE_RATES.vndToUsd / EXCHANGE_RATES.krwToUsd)
Rút gọn = fixedCostKRW × 1350 × (25500/1350) = fixedCostKRW × 25500
Ví dụ: 1,000,000 KRW học phí hiển thị thành 25,500,000,000 VNĐ thay vì ~18,900,000 VNĐ. Sai gấp 1,349 lần.
🔴 BUG-003 [CRITICAL SECURITY] — Route reset admin password không có auth
server.js:217: Route POST /api/reset-admin-password không có middleware xác thực.
Bất kỳ ai cũng gọi được → reset password admin về admin123 → chiếm toàn bộ hệ thống.
server.js:979: Credential admin@duhoccost.vn / admin123 được log ra console khi khởi động.

5Test Strategy

Các loại test sẽ thực hiện

  • Unit Tests: Calculation engine, currency conversion, validation functions
  • Integration Tests: API endpoints với real PostgreSQL
  • E2E Tests: Vitest + Playwright — luồng đăng ký → tính phí → tracking
  • Smoke Tests: Sau mỗi deploy — 10 test cases quan trọng nhất
  • Performance Tests: k6 — 50 concurrent users, response <500ms
  • Security Tests: OWASP ZAP scan, manual pentest auth routes
  • Regression Tests: Bộ test cases tự động chạy khi merge PR

Test Data Strategy

  • University data: Dùng Table_1.csv gốc (6 trường mẫu có trong repo)
  • Edge case data: Trường không cấu hình visa, trường Top 3, trường TOPIK 100%
  • Boundary data: Học phí = 0, = 999,999,999 KRW; Học bổng = 0%, = 100%
  • Invalid data: Học phí âm, TOPIK > 6, GPA > 10, file CSV rỗng
  • Real-world data: Ajou, Sejong, Konkuk từ CSV mẫu đã có
Ưu tiên test: Module E (Calculation Engine) → Module C (Import CSV) → Module A+B (Admin) → Module D (Student Detail)
